# FDE Toolkit

Repositorio de herramientas y metodología de desarrollo reutilizables.
Para añadir o cambiar módulos, lee [PLAYBOOK.md](PLAYBOOK.md).

Si el encargo es instalar o configurar las herramientas, sigue [INSTALL.md](INSTALL.md).

- `tools/hook-me-up/`: notificaciones nativas para responder a Claude Code.
- `methodology/agent-workflow/`: skill común, roles e instalación para Claude Code,
  Codex y Herdr Core.
- `.claude-plugin/marketplace.json`: catálogo de plugins del toolkit.

Para trabajar con la metodología, lee primero
`methodology/agent-workflow/skills/agent-workflow/SKILL.md` y las referencias
pertinentes. Las reglas de negocio, arquitectura y validación de cada proyecto
pertenecen a sus propias instrucciones. Los perfiles y el estado privado quedan
fuera de este repositorio.
